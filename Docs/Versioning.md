# Версии плагина и версии движка

Бинарники Unreal-плагина привязаны к версии движка (5.8, 5.9, …), а код между версиями иногда расходится.
Поэтому линии под разные движки живут в отдельных ветках, а каждый релиз — отдельный неизменяемый тег.
Выпуск под новый движок ничего не перезаписывает: релизы под 5.8 остаются на месте.

## Ветки

| Ветка | Назначение |
|---|---|
| `main` | разработка под актуальный движок (сейчас 5.8) |
| `ue5.8`, `ue5.9`, … | линия под конкретный движок: только то, что собирается и проверено на нём |

- Пока код одинаково собирается на всех поддерживаемых движках, работаем в `main`, а `ue<x.y>` просто догоняет его
  (`git merge main`). Мелкие различия API закрываем макросами из `Misc/EngineVersionComparison.h`:
  ```cpp
  #if UE_VERSION_NEWER_THAN(5, 8, 0)
  	// 5.9+
  #else
  	// 5.8
  #endif
  ```
- Когда новый движок требует несовместимых правок, `main` переходит на него, а старая ветка (`ue5.8`) замораживается
  и дальше получает только исправления — через `git cherry-pick` из `main` или прямые коммиты.
- Ветку под новый движок создаём от `main` в момент перехода: `git switch -c ue5.9 main`.

## Версия плагина

`VersionName` в `IluUnrealTool.uplugin` — semver (`0.2.0`), `Version` — целое, растёт на каждый релиз.
Номер общий для всех движков: одна и та же функциональность под 5.8 и 5.9 — одна версия.
Изменения пишутся в [CHANGELOG.md](../CHANGELOG.md).

## Теги и релизы

Тег = версия плагина + движок: `v0.2.0-ue5.8`, `v0.2.0-ue5.9`, `v0.2.1-ue5.8`.
Тег ставится на коммит ветки этого движка, на GitHub к нему — Release с собранным zip.

```powershell
# 1. Собрать пакет под движок (ветка ue5.8, движок 5.8)
.\Scripts\Package.ps1 -EngineDir "D:\Software\UE_5.8"
# -> Build\IluUnrealTool-0.2.0-UE5.8-Win64.zip

# 2. Тег и релиз
git tag -a v0.2.0-ue5.8 -m "IluUnrealTool 0.2.0 for UE 5.8"
git push origin v0.2.0-ue5.8
gh release create v0.2.0-ue5.8 Build\IluUnrealTool-0.2.0-UE5.8-Win64.zip --title "0.2.0 (UE 5.8)" --notes-file CHANGELOG.md
```

Пакет хранит `"EngineVersion": "5.8.0"` и `"Installed": true` — редактор другой версии такой пакет не загрузит
и предложит пересобрать. Ставится распаковкой в `<Engine>\Engine\Plugins\Marketplace\`.

## Чек-лист выпуска под новый движок

1. `git switch -c ue<x.y> main` (или продолжить в `main`, если правок не нужно).
2. Собрать: `.\Scripts\Package.ps1 -EngineDir <новый движок>`, починить ошибки компиляции.
3. Проверить в редакторе: тулбар (Play Here, Place Actor, «⋮»), колесо Time Of Day, Mesh Ops, MCP-тулсеты
   (`IluUnrealToolAgent.*` видны агенту).
4. Обновить таблицу «Движок» в README и CHANGELOG, поставить тег `v<версия>-ue<x.y>`, выпустить релиз.
